# Nrage Assistant — Resizable menu (v1.14.0)

The menu on the left of the window can now be made wider, so long tab names are no longer cut off.

## ✨ New

### Window
- Drag the **right edge of the menu** to make it wider or narrower (from 160 to 360 units). The edge lights up under
  the pointer
- **Double-click** the edge to put back the default width
- The width is saved for your whole account
- In a small window the menu gives way so the page keeps its room, and gets your width back when the window grows

## ⚠️ Good to know

- Nobody has tested the resizable menu in game yet. If something looks wrong, tell an officer
