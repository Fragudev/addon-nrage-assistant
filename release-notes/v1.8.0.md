# Nrage Assistant — Class in enemy alerts (v1.8.0)

Enemy alerts now tell you what you are facing at a glance.

## 🎨 Changes

### PvP Intel alerts
- **Class and level**: the alert names the enemy's class next to the level, for example "Kill on Sight: Bob (Rogue, level 60) <Evil>"
- **Class colour**: in the warning window the class name is shown in its class colour
- Guild reports and chat announcements also include the class, as plain text
- A class or level that is not known is simply left out

## ⚠️ Good to know

- The new alert text has not been checked in the live game yet
