# Nrage Assistant — Realm name fix (v1.16.1)

The addon shows up again for guild members after the latest WoW Forever change.

## 🐛 Fixes

### Access
- The addon no longer turns itself off at login. WoW Forever stopped giving addons the name of the realm, and the
  addon was waiting for it before turning on
- Your saved character data, and the rank settings of the guild, stay as they were

## ⚠️ Good to know

- If the addon still does not show up after updating, type `/reload` once
- This fix has not been checked in the live game yet
