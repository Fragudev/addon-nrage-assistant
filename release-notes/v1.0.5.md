# Nrage Assistant — Stability review (v1.0.5)

A full review of the addon: many small fixes, and safer sync between guildmates.

## 🐛 Fixes

- Text you are typing is saved when you switch tab, and a guild update no longer interrupts you while you type
- Dropdowns and date pickers close when the page updates, so a choice can no longer land on another row
- Banners can always be dismissed, and table headers always sort by the right column
- The loot popup keeps its scroll position and no longer rebuilds itself every second
- A refused loot candidacy stays on screen so you can try again
- A second battleground win soon after the first one now counts for missions
- Names with an accented capital match in the blacklist, and Spanish weekday names and name initials show correctly
- The "Share my layer" switch shows its explanation again

## 🔒 Sync

- Only the guild master and co-guild master can relay PvP season data, so it cannot be forged
- Members who join a full list are no longer refused: the oldest entries make room
- If two seasons are started at once, every client agrees on the same one
- Requests dropped while the guild roster loads are repeated

## ⚠️ Good to know

- Saved data moves to a new format: going back to an older version disables the addon
- Update everyone: older versions and this one refuse each other's blacklist entries for names with an accented capital
- `/nrage pvp grant` accepts names with several words, in any case, and refuses mistyped points
- Commands work in any case, and the `lockdown`, `pvp` and `layer` debug tools are now for development builds only
