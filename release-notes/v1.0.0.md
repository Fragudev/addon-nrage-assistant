# Nrage Assistant — First stable release (v1.0.0)

The first stable release of Nrage Assistant, with the new NRAGE look. The layout and the features are the same as in
beta.11.

## ✨ Features

### Look
- New NRAGE style in red and black
- Panels, cards and buttons have cut corners
- Titles and labels use the Cinzel and Barlow Condensed fonts
- The main window has the castle background

### Text
- The Spanish page descriptions and empty states are written in a more direct voice
