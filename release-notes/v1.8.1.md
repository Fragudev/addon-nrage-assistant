# Nrage Assistant — Clearer access diagnostics (v1.8.1)

A small update to help diagnose why the addon does not unlock for a guild member.

## 🔧 Changes

### /nrage debug identity
- Shows the **addon version**
- Shows the guild **club id** with its type next to the **expected club id**, so a mismatch is easy to spot
- Shows the **access result**: "ok" or the reason access is denied
