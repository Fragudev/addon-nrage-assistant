# Nrage Assistant — Map pins and Intel window (v1.3.0)

Cleaner guild pins on the maps, a taller Intel window when you need it, and a quicker way to open it.

## ✨ Features

### Guild map
- Guildmates now show as **round class icons** inside a ring, on the minimap and the world map
- Pins are always fully opaque; a member on another layer gets a **grey ring** instead of fading out
- Enemy pins from Intel use the same round look with a red ring, grey when the reporter is on another layer

### Intel
- The Intel window now resizes **vertically** too: drag the corner and the height snaps to whole rows (1 to 20)
- The row count you drag to is the same setting as the rows choice in the Intel settings
- New **Intel** entry in the minimap button's right-click menu shows or hides the Intel window

## ⚠️ Good to know

- Resizing still waits for the end of combat and does nothing while the window is locked
- The new pin look has not been checked in the live game yet
