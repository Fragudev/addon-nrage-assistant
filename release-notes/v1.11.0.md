# Nrage Assistant — Groups icon on the minimap (v1.11.0)

You no longer need to open the window to know there are groups: an icon on the minimap tells you, like the mail icon.

## ✨ New

### Groups
- While another member has an open group, a **Groups icon** appears on the edge of the minimap, with the number of
  open groups when there are two or more
- Hover it to see the groups: type, title, leader and the roles they still need; the ones you can join right now are
  shown in green
- Click it to open the Groups tab; drag it to move it around the minimap (its position is remembered)
- Your own group never shows the icon, and it hides when the Groups module is off

## ⚠️ Good to know

- The icon only knows the groups of members who run the addon, like the Groups board
