# Nrage Assistant — Professions and guild map (v1.0.3)

Recipes are easier to read, and the guild map works without setup.

## ✨ Features

### Professions
- Each recipe has one dropdown with everyone online who can craft it, instead of a button per person
- Picking a name opens the chat with the whisper ready to send
- When nobody is online, the dropdown is disabled and its tooltip names who can craft the recipe

### Guild map
- Your position is now shared with the guild by default. Instances, battlegrounds and encounters still send nothing
- This turns sharing on once for everyone, with a notice in the chat. You can turn it off in the settings, and it stays off
