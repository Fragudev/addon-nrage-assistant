# Nrage Assistant — Layer swaps wait for the end of combat (v1.13.0)

A layer swap request no longer pops up in the middle of a fight: it waits next to the Groups icon until combat ends.

## 🔧 Changed

### Layers
- When a guildmate asks for a layer swap while you are **in combat**, the popup and its sound wait. A small icon shows
  next to the Groups icon instead, and the popup opens by itself **when combat ends**
- Hover the icon to see who asks and the time left, or click it to open the popup right away
- You are now asked even if the request arrives while you fight. **Help** and **Invite** still wait for the end of
  combat
- A popup that was already open when combat started stays open and keeps updating

## ⚠️ Good to know

- Nobody has tested the combat icon in game yet. If something looks wrong, tell an officer
